Google HTML → PagePilot

Одно расширение Chrome для MacBook и Windows. Использует ваш открытый Chrome и сессию Google. Отдельная оплата облачного браузера не нужна.

Скачать ZIP для macOS и Windows

  1. Распакуйте ZIP: на macOS — двойным щелчком в Finder; на Windows — «Извлечь всё». Сохраните папку в постоянном месте.
  2. В Chrome откройте chrome://extensions и включите «Режим разработчика».
  3. Нажмите «Загрузить распакованное расширение» и выберите папку pagepilot-chrome, содержащую manifest.json.
  4. Обновите вкладку PagePilot. Откройте задачу шаблона → HTML конкурентов. Укажите адрес и нажмите «Получить через Chrome».
  5. Оставьте PagePilot открытым. В новой вкладке Google дождитесь проверки. HTML сохранится в поле соответствующего конкурента.

Если Google требует участия

Войдите в Google или пройдите CAPTCHA самостоятельно. Откройте «Просмотреть проверенную страницу → HTML», нажмите значок расширения и «Забрать HTML». Если Google изменил интерфейс, скопируйте весь HTML и вставьте в поле PagePilot — оно сохраняется автоматически.

Как это работает

Расширение читает код проверенной страницы из редактора Google, а не код интерфейса теста. Токен PagePilot используется только в его вкладке для сохранения. Пароль Google и cookies не извлекаются. После обновления или закрытия вкладки PagePilot начните получение заново. При конфликте сохранений скопируйте HTML и обновите задачу.

Обновление расширения

Распакуйте новую версию в ту же папку и нажмите «Обновить» на карточке расширения в chrome://extensions. Обновите вкладки PagePilot и Google.
