# План главных страниц датских миниобзорников

Состав группы и индивидуальные наборы брендов сохранены в отчёте 3027. Использовать только обзорники команды 4:19; монобренды не включать. Для каждого проекта — уникальное множество минимум из трёх брендов. Имеющиеся уникальные наборы можно сохранить. До изменения проверить реальный источник витрины; пустая выборка карточек не доказывает отсутствие витрины.

В отчёте разделять исходное количество брендов, планируемое и подтверждённое после публикации. Сохранять исходные карточки и условия; не смешивать офферы. Проверять доступность бренда для DK и факты по официальным источникам.

Для мета главных страниц рекомендуется, но не требуется, формулировка наподобие «Top 3 casinoer i Danmark». Число должно соответствовать фактическому составу витрины. Title и Description разнообразить на языке проекта, согласовывать с текстом, не использовать один обязательный шаблон.

Содержание — рабочие ссылки-якоря на уникальные id разделов. Публиковать в существующую главную /, сохраняя витрину после H1.
