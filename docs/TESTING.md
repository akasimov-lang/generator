# Проверки по области изменения

Сначала перечисляйте файлы текущей задачи. Не используйте всё грязное рабочее дерево как список изменений: оно содержит несколько независимых задач.

```sh
python scripts/check_changes.py backend/app/auto_pilot.py frontend/src/AutoPilot.tsx
python scripts/check_changes.py --run backend/app/reglue_reserves.py
```

Первая команда только показывает план. `--run` выполняет выбранные проверки:

- backend: тест соответствующего модуля и явно известные проверки зависимых функций;
- для остальных backend-модулей — одноимённые тесты и тесты с прямыми импортами этого модуля;
- frontend: TypeScript и сборка при изменении исходников; соответствующий Node-тест, если он существует;
- документация и отчёты не запускают приложение и тесты;
- локальные браузерные сценарии не запускаются.

Если правка меняет контракт вызываемого модуля, добавьте тест вызывающей стороны через `--test backend/tests/test_....py`. Для неизвестного узла скрипт останавливается и требует явного выбора проверок. Это помощник выбора, а не доказательство отсутствия всех косвенных зависимостей.

Изменение общих моделей, БД, зависимостей backend, миграций или общей фикстуры требует полного backend-набора. Полный прогон в остальных случаях обосновывается отдельно; повторять успешные проверки без изменения кода или новой причины не нужно.

Для Auto Pilot:

| Изменённый узел | Проверки |
| --- | --- |
| Отчёт и отображаемые результаты | `test_auto_pilot.py` + сборка frontend, если менялся интерфейс |
| Повторная проверка Webdev | `test_reglue_recheck.py`, `test_auto_pilot.py` |
| Сохранение Title/H1 | `test_reglue_title_h1.py`, `test_reglue_recheck.py` |
| База резервов | `test_reglue_reserves.py` |
| Доли и распределение схем | `test_pilot_variations.py`, `test_auto_pilot.py` |
| Интервалы повторных проверок | `test_transfer_confirmation.py` |

Google Chrome, Chromium и Playwright на Mac пользователя не запускать. Браузерные сценарии сохраняются как покрытие, но не входят в локальную автоматическую процедуру. Их возможный перенос на отдельный CI-хост — отдельная задача.
