# Заметки проектов

В шапке проекта и таблицах проектов доступна иконка бумажного стикера. Непустая заметка отмечается ручкой и строками текста. Стикер можно перемещать за верхнюю панель, закрывать крестиком или Escape. Клавиши направления перемещают сфокусированную верхнюю панель.

Текст общий для проекта и сохраняется в PagePilot автоматически через 650 мс после ввода. Зелёная дискета слева внизу мерцает при сохранении и горит ровно после подтверждения; ошибка обозначается другим цветом и пояснением. Черновик дополнительно хранится в sessionStorage отдельно для пользователя и проекта. При закрытии и смене проекта запускается немедленное сохранение. При сетевой ошибке доступны повтор и автоматическая попытка после восстановления соединения. Несохранённый текст вызывает предупреждение браузера при уходе со страницы.

Запись хранится в существующей таблице AutoReglueConfig, ключ `project-note:<site UUID>`. Текст не отправляется в Webdev и не публикуется на сайтах. Права проверяются по доступу к проекту. PUT сравнивает revision под блокировкой строки проекта, чтобы параллельные записи не перетирали друг друга. Повтор идентичного текста безопасен. При конфликте показывается текущая серверная версия и сохраняется локальный черновик.

Таблицы проектов (общая, избранные, массовые действия и встроенные выборки) получают пакетный индекс непустых заметок. Приоритет применяется до пагинации, сохраняя выбранную сортировку внутри групп. Пробельный текст не даёт приоритета. Изменения сразу обновляют индекс текущей страницы; при возвращении фокуса индекс перечитывается.

Проверки: `backend/tests/test_project_notes.py`, `frontend/tests/projectNoteOrder.test.mjs`. `frontend/tests/projectStickyHarness.jsx` и `frontend/vite.sticky.config.ts` собирают изолированный стенд для `frontend/tests/project_sticky_browser.py`; запуск браузера только на сервере с переданным `FIXTURE_HTML`, без реальных записей проектов.
