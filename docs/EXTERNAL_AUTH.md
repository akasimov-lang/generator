# Авторизация и доступ к проектам через Webdev

Единственный вход — `POST /api/auth/login`, который передаёт `{username, pass}`
в `https://o59s9a012jd.com/auth/login`. Возвращается внешний токен без выпуска
локального токена. Пароль не сохраняется. Каждый токен проверяется через
`GET /auth/me`; имя берётся из подтверждённого профиля, а не из формы входа
или неподписанного содержимого токена.
Запрос получения токена содержит `Origin` со значением `APP_PUBLIC_URL`
(`https://ai-seo-content-panel.site` в production).
Запрос входа не передаёт старый browser token и запрашивает новый token в Webdev.
Если Webdev отклоняет сам `/auth/login`, PagePilot возвращает браузеру исходные
HTTP-статус, тело ответа и `Content-Type`, не преобразуя `400/401/403` в единый `401`.
Если Webdev выдал token, но сразу отклонил его в `/auth/me`, PagePilot запрашивает ещё один новый
token и повторяет проверку один раз. Отказ проверки уже выданного токена показывается отдельно.

Любой пользователь, успешно подтверждённый Webdev через `/auth/me`, получает
одинаковый полный доступ PagePilot ко всем разделам, действиям и проектам.
Имя пользователя и назначения ответственных в Webdev не меняют уровень доступа.

Успешная проверка чтения кешируется максимум на 30 секунд, отдельно по хешу
токена, без сохранения токена в кеше. Вход, `/auth/me` и изменяющие запросы
выполняют свежую проверку. При ошибке внешнего сервиса нет перехода на локальные
пароли или сервисный токен для получения пользовательских прав. Внешний `401/403`
завершает сессию, временная недоступность возвращает `503`.

В API все подтверждённые пользователи проходят административные проверки и работают
с полным набором проектов. Прямые и переданные в теле запроса идентификаторы
по-прежнему проверяются на существование и корректность до выполнения действия.
Сервисные настройки интеграции остаются для фоновых заданий и существующих операций,
но не используются для входа пользователей и определения их прав.

Раздел «Сайты» и кнопка «Обновить проекты» доступны каждому пользователю.
Кнопка вызывает `POST /sites/cache/sync`: права проверяются заново, данные
Webdev фильтруются по разрешённым именам и серверам, новые доступные проекты
импортируются, затем браузер перечитывает список. Без назначений внешний кеш
не запрашивается. Глобальная фоновая синхронизация остаётся административной.

Локальные создание пользователей, назначение ролей, смена и сброс паролей
удалены из API и интерфейса. Миграция `0050_external_auth` стирает локальные
хеши паролей и прежние роли; идентификаторы пользователей остаются для истории
и избранного. При подтверждённом внешнем входе локальная запись обновляется
только как профиль, без пароля. Автоматическое создание администратора из
`ADMIN_USERNAME` / `ADMIN_PASSWORD` удалено. Старые локальные токены не принимаются.

Браузер хранит список проектов отдельно для каждого пользователя и удаляет старый
общий снимок. Проверка сессии выполняется каждый час и при возврате фокуса.
Полный список проектов обновляется вручную; при отсутствии снимка однократно
загружается список из БД.

Проверки: серверные тесты внешнего контракта, полного доступа, отказов,
прямых ссылок, массовых запросов, фоновых задач и прежних локальных учётных записей;
браузерные проверки входа, ошибки сервиса, одинакового доступа разных аккаунтов,
истечения токена и удаления управления локальными паролями.

## Служебная учётная запись PagePilot

Все серверные обращения к Webdev для операций с проектами, публикаций, массовых
действий и автоматического переклея используют `PROJECT_CACHE_USERNAME=ai_seo_419`
и `PROJECT_CACHE_PASSWORD` из закрытой серверной `.env`. Пароль не хранится в Git.
Поля `initiator` и `username` в исходящих операциях указывают служебный аккаунт;
локальная история PagePilot сохраняет также пользователя, запустившего действие,
или `scheduler`. Вход пользователей по-прежнему выполняется с их личными токенами; действующие
права PagePilot сохраняются.
После смены доступов необходимо пересоздать backend, workers, beat и project_stream,
чтобы уже открытые соединения и кеш настроек перешли на новую учётную запись.
