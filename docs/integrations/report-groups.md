# Группы планов и отчётов

Компактные переключатели на странице `/auto-reglue/pilot/report`: Все, Вёрстка, Витрины, Переклеи, Бренды, Прочее. Один отчёт относится к одной группе по основному виду работ; комбинированные задачи с витринами относятся к Витринам.

`pilot_report_groups.group()` сначала учитывает явное `payload.report_group`, затем тип задания и сохранённую выборку. Переклеи с одним включённым брендом и брендовые программы относятся к Брендам. Исключение бренда из массовой выборки и общие ключи остаются в Переклеях. Упоминание бренда в названии отчёта по меню/футеру не делает его брендовым переклеем. Для старых maintenance-отчётов используются признаки выполненных работ и название; сохранённый дизайн неизменяемой витрины не считается работой с ней.

API `/auto-reglue/pilot/tasks` принимает `group`, возвращает `group` у строк и `group_counts` по всей доступной выборке после поиска, до фильтра группы и пагинации. Чужие, скрытые и недоступные отчёты исключаются до подсчёта. Переключение группы сбрасывает страницу, сохраняет поиск и группу в URL. Серверный и браузерный кеши разделены по группе; открытие вкладки не запускает работы.

Проверки: `test_pilot_report_groups.py`, `test_pilot_task_cache.py`, `PilotReportGroups.test.mjs`; серверный сценарий `frontend/tests/pilot_report_groups_browser.py` (не запускать браузер на Mac).
