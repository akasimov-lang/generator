# Ручное поле GSC

В общей шапке каждого проекта, справа в строке последнего обновления, находится компактное текстовое поле GSC без кнопок. Поле не ограничено форматом URL или email, максимум — 2000 символов. Изменения сохраняются после паузы ввода 700 мс, при потере фокуса или Enter. Пустое значение очищает запись.

Значение хранится только в БД PagePilot: отдельная запись `AutoReglueConfig` с ключом `project-private:gsc:<site_id>`. Оно не является частью `Site`, конфигурации Webdev, данных публикации, отчётов или задач Fibery. При смене Main, имени проекта и синхронизации сайта запись сохраняется по неизменному ID проекта. Запись не запускает синхронизацию, обновление отчётов или уведомления. Доступ ограничен правами пользователя на проект.

API: `GET /api/sites/{site_id}/gsc`, `PUT` по тому же адресу с JSON `{"value":"..."}`. Оба ответа имеют `Cache-Control: no-store`. Автоматического подключения к Google Search Console нет. Интерфейс не сохраняет данные в localStorage/sessionStorage. При ошибке запись остаётся в поле с пометкой «Не сохранено»; Enter повторяет попытку. Пока исходное значение не загружено, редактирование запрещено.
