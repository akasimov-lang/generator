# SEO-задача Fibery после переклея

При наличии `FIBERY_API_TOKEN` в секретном окружении подтверждённый переклей
PagePilot создаёт отложенное задание `fibery_reglue`. Это относится к ручным,
автоматическим и межсетевым переклеям, которые проходят через общий журнал
`NetworkOperation`. Обычное обновление кэша без подтверждённой операции не
выдаётся за известный переклей.

- Название: `Переклей: исходный домен → новый домен`.
- Привязка: номер `#…` из сохранённого имени Fibery проекта, проверенный через API.
  Если привязки нет, запись ждёт её восстановления; произвольный проект не выбирается.
- Отсчёт: `confirmed_at`, а не время нажатия кнопки. Внешняя запись не выполняется
  раньше чем через 180 секунд. После границы задание забирает штатная очередь.
- Окно отчёта: от −180 до +180 секунд включительно, только работы того же проекта.
  Отчёт сохраняется перед обращением в Fibery и не расширяется при повторных попытках.
- Содержимое: Main, фейковый путь, разметка и состояние альтернейтов до/после,
  операции сетки, редакторские изменения, подготовка текстов/изображений и публикации.
  Неподтверждённые операции указаны отдельно по статусу, без заявления об успехе.
- Источники: сохранённые квитанции и снимки. Отсутствующие исторические данные
  отмечаются явно; текущее состояние не подставляется в раздел «было».
- UUID задачи детерминирован по ID переклея. После таймаута сначала выполняется
  чтение этого UUID. Название, связь с SEO-проектом, текст описания и состояние
  подтверждаются чтением. Чужое изменённое описание не перезаписывается.
- Задача получает состояние `Closed` после подтверждения описания. Ссылка и
  результат выводятся в примечаниях проекта (`FIBERY_REGLUE`); незавершённые и
  последняя завершённая запись видны среди актуальных примечаний. История сохраняется.
- Автоматические повторы ограничены интервалом 1–30 минут, без создания новых UUID.
  После остановки воркера задание восстанавливается через 15 минут.

Сканер раз в 15 секунд восстанавливает пропущенные задания начиная с даты в
`AutoReglueConfig['fibery-reglue:enabled-at']`. При первом включении без этой
настройки сохраняется текущее время; старые переклеи автоматически не импортируются.
Для согласованного восстановления конкретного прошлого переклея можно вызвать
`ensure_job(db, operation)` и зафиксировать транзакцию. Повторный вызов безопасен.

Ключ хранится только в секретном окружении, не в Git, описаниях или квитанциях.
Разрешён только рабочий домен Fibery `https://hzhz.fibery.io`, перенаправления API
не выполняются. Прямой HTTP-ответ с ошибкой не сохраняется в журнале.
