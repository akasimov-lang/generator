# Проверка Main и основного внутряка по брендам

Отчёт `brand_health_audit` — сохранённая таблица проверки, без рерайта, публикации или переклея. Состав фиксируется до запуска; текущая группа: Pelican, Fontan, BetOnRed, Lemon Casino. Скрытые/удалённые проекты исключены, дополнительного ограничения по статусу нет.

Запуск: `python -m app.brand_health_audit <UUID заранее созданного отчёта>`. Возобновление пропускает завершённые строки. Проверяются текущие адреса из Webdev; если Webdev недоступен, используется сохранённая конфигурация с явной пометкой. HTTPS проверяется с валидным TLS, каждое перенаправление проверяется на публичность адреса; не более 8 переходов, HTML до 2 МБ. Неположительные результаты проверяются дважды. Сохраняются дата, цепочка HTTP-ответов, Title, короткий фрагмент текста и хеш HTML. HTTP 200 сам по себе не означает работоспособность: стандартные короткие welcome/parking страницы отмечаются заглушками, посторонний контент — требующим проверки, CAPTCHA — блокировкой проверки. Вложения, формы, игры, оплаты и все остальные домены сетки не тестируются.

Таблица содержит ссылки на PagePilot, связанный Fibery-проект, точный Main и выбранный внутряк, результаты обеих проверок и компактное поле GSC. Оно обращается к отдельному приватному API проекта; значение GSC не копируется в снимок отчёта, Webdev или Fibery. Подробности раскрываются по строке. Есть фильтры по бренду, заглушкам Main и всем проблемам.
